# Contributing to The Lunar Org

Thank you for your interest in contributing. We value simplicity, focused changes, and deliberate code.

### Workflow

1. **Discuss First:** For new features or architecture changes, open an issue first to discuss the idea.
2. **Branching:** Use short descriptive branch names (`feat/...` or `fix/...`).
3. **Keep it Focused:** Keep pull requests concise and centered around a single change or fix.
4. **Code Quality:** Ensure code is well-formatted, clean, and free of extraneous dependencies.

### Commit Messages

We appreciate clear, descriptive commit messages following standard conventions (`feat:`, `fix:`, `docs:`, `refactor:`).
