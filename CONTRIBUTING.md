# Contributing to The Lunar Org

We value quiet craftsmanship, thoughtful discussions, and deliberate code. Thank you for taking the time to contribute to our ecosystem.

---

## Philosophy

Before submitting contributions, please keep our core tenets in mind:
- **Simplicity over complexity:** Prefer clean, straightforward solutions over clever or unnecessary abstractions.
- **Minimal dependencies:** Avoid introducing new external libraries unless strictly required.
- **Respectful communication:** Be kind, constructive, and patient in code reviews and discussions.

---

## Getting Started

1. **Find or open an issue:** Before writing significant code, please check existing issues or open an issue to discuss your proposal.
2. **Fork and branch:**
   ```bash
   git checkout -b feat/your-feature-name
   # or
   git checkout -b fix/issue-description
   ```
3. **Commit conventions:** We follow [Conventional Commits](https://www.conventionalcommits.org/):
   - `feat:` A new feature or capability
   - `fix:` A bug fix
   - `docs:` Documentation improvements
   - `refactor:` Code refactoring without behavior change
   - `test:` Adding or improving tests
   - `chore:` Maintenance, dependency updates, or CI adjustments

---

## Pull Request Process

1. Ensure existing tests pass and add new tests where applicable.
2. Verify code adheres to the project's linter and formatter.
3. Keep pull requests focused on a single logical change.
4. Fill out the pull request template completely and clearly.
5. Maintainers will review your PR with care and provide constructive feedback.

Thank you for building with us.
