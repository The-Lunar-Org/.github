# Security Policy

The Lunar Org takes security, stability, and data privacy seriously. We appreciate the responsible disclosure of any potential vulnerabilities.

## Supported Versions

Only the latest `main` branch releases of active projects in this organization receive security patches and updates.

| Project | Supported Versions | Status |
| :--- | :--- | :--- |
| **lunar-bot** | `main` | :white_check_mark: |
| **All Other Active Repos** | `main` / latest release | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability or exploit within any Lunar Org codebase, please do **not** open a public issue.

Instead, please report it via one of the following confidential channels:

1. **GitHub Private Vulnerability Reporting**:
   Navigate to the **Security** tab of the relevant repository and click **"Report a vulnerability"**.
2. **Direct Contact**:
   Reach out directly to the maintainer via:
   - Dev: [@ItsHimanshu-Raj](https://github.com/ItsHimanshu-Raj)
   - X: [@1tsRaj](https://x.com/1tsRaj)

### What to Include

Please provide:
- A detailed description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
- Any recommended remediation steps, if known.

### Response Commitment

- **Acknowledgment:** Within 48 hours.
- **Triage & Assessment:** Within 5 business days.
- **Public Disclosure:** Coordinated only after a fix has been verified and deployed.

Thank you for helping keep our software calm, safe, and reliable.
